Bookmark Revive AI · Politique de confidentialité

Dernière mise à jour : 24 novembre 2026

Présentation

Bookmark Revive AI (« l'extension ») est une extension Chrome pour nouvel onglet qui vous aide à redécouvrir vos favoris oubliés. Elle fonctionne en priorité en local : le développeur n'exploite aucun serveur et ne collecte, ne reçoit ni ne vend aucune de vos données.

Données lues et modifiées par l'extension

  • Bookmarks (permission bookmarks) : les titres, URL et dossiers sont lus afin de les afficher, de les rechercher et de les faire défiler sur la page du nouvel onglet. Les signets ne sont modifiés que par une action de votre part : ajouter un élément à Favoris avec « Also save to Chrome bookmarks » crée un signet dans le dossier de votre choix ; modifier un élément de Favoris lorsque la synchronisation est activée met à jour l'URL de ce signet ; cliquer sur « Delete » sur une carte et confirmer deux fois supprime ce signet.
  • Sites les plus visités (permission topSites) : les 8 premiers sont utilisés comme Favoris initiaux lors de la première installation, et pour ajuster la pondération si vous activez « boost frequently visited sites ».
  • Icônes de sites (permission favicon) : chargées via l'API intégrée de Chrome ; vos URL ne sont jamais envoyées à un tiers pour récupérer des icônes.
  • Alarmes (permission alarms) : utilisées uniquement pendant l'exécution de « Generate summaries for all bookmarks », afin de reprendre la tâche si Chrome suspend le processus en arrière-plan.

Où les données sont stockées

Toutes les données (Favoris, Sélection, nombre de clics, historique d'affichage, cache des résumés, paramètres et les clés API que vous saisissez) sont stockées uniquement dans le stockage local des extensions de votre navigateur (chrome.storage.local). Elles ne sont jamais synchronisées vers le développeur ni vers un quelconque serveur. La désinstallation de l'extension supprime ces données.

Fonctionnalité facultative : résumés IA en une ligne

  • Cette fonctionnalité est désactivée par défaut. Elle ne s'exécute qu'après que vous avez lu l'avis de confidentialité dans les paramètres, coché la case de consentement, saisi votre propre API Key et l'avez activée.
  • Lorsqu'elle est activée, l'extension envoie le titre, le domaine et le nom du dossier des signets nécessitant un résumé, directement depuis votre navigateur vers le fournisseur d'IA que vous avez choisi, afin de générer un résumé en une ligne. Les requêtes utilisent votre propre API Key et sont facturées sur votre compte auprès de ce fournisseur.
  • Fournisseurs intégrés : DeepSeek (api.deepseek.com) et Google Gemini (generativelanguage.googleapis.com). L'accès à ces deux domaines est accordé à l'installation.
  • Vous pouvez aussi choisir « Custom provider » et saisir un point de terminaison. Dans ce cas, l'extension demande à Chrome l'accès à ce seul domaine, et uniquement lorsque vous cliquez sur « Save », « Test connection » ou « Fetch » ; elle ne demande jamais l'accès à un autre site. Si vous passez à un autre point de terminaison, l'accès à l'ancien domaine est révoqué.
  • Jamais envoyés : l'historique de navigation complet, le contenu des pages, les cookies, les mots de passe ou toute information permettant de vous identifier personnellement.
  • Le traitement de ces données par le fournisseur que vous avez choisi est régi par la politique de confidentialité propre à ce fournisseur ; veuillez la consulter avant utilisation.
  • Les résumés sont mis en cache localement par URL et ne sont pas renvoyés. La page du nouvel onglet elle-même n'appelle jamais l'IA ; des requêtes ne sont envoyées que lorsque vous cliquez sur « Start generating » ou « Test connection ». Vous pouvez désactiver la fonctionnalité ou retirer votre consentement à tout moment ; pour supprimer les résumés générés, cliquez sur « Clear summary cache » dans les paramètres.

Lien de soutien

L'icône de café en haut à droite des paramètres n'est qu'un lien de soutien : en chinois simplifié, elle affiche une image de code QR de don WeChat incluse dans l'extension ; dans les autres langues, elle ouvre Ko-fi (ko-fi.com). L'extension n'inclut aucun SDK de paiement et n'envoie aucune de vos données à ces pages.

Ce que nous ne faisons pas

  • Nous ne collectons aucune information personnelle identifiable, aucun historique de navigation ni aucune statistique d'utilisation.
  • Nous n'utilisons aucun code d'analyse, de publicité ou de suivi.
  • Nous ne vendons ni ne transférons les données des utilisateurs, et ne les utilisons pas à des fins étrangères à l'objectif unique de l'extension.
  • Nous n'utilisons pas les données des utilisateurs pour évaluer leur solvabilité ni à des fins de prêt.

Politique relative aux données utilisateur du Chrome Web Store

L'utilisation des données des utilisateurs par cette extension respecte la politique relative aux données utilisateur du Chrome Web Store, y compris les exigences d'utilisation limitée.

Confidentialité des enfants

L'extension ne s'adresse pas aux enfants de moins de 13 ans et ne collecte pas sciemment d'informations auprès d'enfants.

Modifications de cette politique

Si cette politique change, nous mettrons à jour la date en haut de cette page. Les changements importants concernant l'utilisation des données seront annoncés dans les notes de mise à jour de l'extension.
