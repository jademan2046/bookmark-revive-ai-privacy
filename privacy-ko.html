Bookmark Revive AI · 개인정보 처리방침

최종 업데이트: 2026년 11월 27일

개요

Bookmark Revive AI(이하 "확장 프로그램")는 잊고 있던 북마크를 재발견하도록 도와주는 Chrome 새 탭 확장 프로그램입니다. 로컬 우선 방식으로 동작하며, 개발자는 서버를 운영하지 않고 사용자의 데이터를 수집, 수신 또는 판매하지 않습니다.

확장 프로그램이 읽고 변경하는 데이터

  • 북마크(bookmarks 권한): 새 탭 페이지에서 북마크를 표시, 검색, 순환하기 위해 제목, URL, 폴더를 읽습니다. 북마크는 사용자가 직접 조작할 때만 변경됩니다. "Chrome 북마크에도 저장"을 선택하고 즐겨찾기를 추가하면 사용자가 선택한 폴더에 북마크가 생성되고, 동기화가 켜진 상태에서 즐겨찾기를 수정하면 해당 북마크의 URL이 업데이트되며, 카드의 "삭제"를 클릭하고 두 번 확인하면 해당 북마크가 삭제됩니다.
  • 자주 방문하는 사이트(topSites 권한): 처음 설치할 때 상위 8개를 초기 즐겨찾기로 사용하며, "자주 방문하는 사이트 가중치 높이기"를 켠 경우 가중치를 조정하는 데에도 사용합니다.
  • 사이트 아이콘(favicon 권한): Chrome의 내장 API를 통해 불러오며, 아이콘을 위해 사용자의 URL이 제3자에게 전송되는 일은 없습니다.
  • 알람(alarms 권한): "모든 북마크의 요약 생성"이 실행되는 동안에만 사용되며, Chrome이 백그라운드 프로세스를 중단했을 때 작업을 재개하기 위한 것입니다.

데이터 저장 위치

즐겨찾기와 후보 목록(제목, URL, 순서)은 Chrome 동기화(chrome.storage.sync)를 통해 사용자의 Google 계정에 저장되며, 같은 계정으로 로그인한 다른 기기에서 자동으로 복원됩니다. Chrome에 로그인하지 않았거나 동기화가 꺼져 있으면 이 기기에만 저장됩니다. 확장 프로그램을 삭제하면 Chrome이 이 동기화 데이터도 함께 삭제합니다. 그 밖의 데이터(클릭 횟수, 노출 기록, 요약 캐시, 설정 및 사용자가 입력한 API Key)는 브라우저의 로컬 확장 프로그램 저장소(chrome.storage.local)에만 저장되며 동기화되지 않습니다. 이 확장 프로그램은 어떤 데이터도 개발자나 개발자 서버로 보내지 않습니다(개발자는 서버를 운영하지 않습니다). 설정에서 내보낸 AI 요약 백업 파일은 사용자가 선택한 위치에만 저장되며 API Key를 포함하지 않습니다.

선택 기능: AI 한 줄 요약

  • 이 기능은 기본적으로 꺼져 있습니다. 설정에서 개인정보 안내를 읽고, 동의 체크박스를 선택하고, 본인의 API Key를 입력한 후 켜야만 실행됩니다.
  • 켜면 확장 프로그램은 요약이 필요한 북마크의 제목, 도메인, 폴더 이름을 브라우저에서 사용자가 선택한 AI 제공업체로 직접 전송하여 한 줄 요약을 생성합니다. 요청은 사용자의 API Key를 사용하며 해당 제공업체의 사용자 계정으로 비용이 청구됩니다.
  • 기본 제공업체: DeepSeek(api.deepseek.com) 및 Google Gemini(generativelanguage.googleapis.com). 설치 시에는 이 도메인에 대한 접근 권한이 부여되지 않습니다. AI를 켜고 "저장", "연결 테스트" 또는 "가져오기"를 클릭할 때만 선택한 한 곳의 도메인에 대한 접근을 Chrome에 요청합니다. 거부하면 요청이 전송되지 않습니다. 다른 제공업체로 바꾸면 이전 도메인의 권한은 회수됩니다.
  • "사용자 지정 제공업체"를 선택하고 엔드포인트를 입력할 수도 있습니다. 이 경우 확장 프로그램은 Chrome에 해당 도메인 하나에 대해서만 접근 권한을 요청하며, 이는 "저장", "연결 테스트" 또는 "가져오기"를 클릭할 때만 이루어지고 다른 사이트에 대한 접근은 절대 요청하지 않습니다. 다른 엔드포인트로 전환하면 이전 도메인에 대한 접근 권한은 취소됩니다.
  • 절대 전송되지 않는 정보: 전체 방문 기록, 페이지 내용, 쿠키, 비밀번호 및 모든 개인 식별 정보.
  • 선택한 제공업체가 이 데이터를 처리하는 방식은 해당 제공업체의 개인정보 처리방침에 따르므로, 사용 전에 반드시 검토하시기 바랍니다.
  • 요약은 URL별로 로컬에 캐시되며 다시 전송되지 않습니다. 새 탭 페이지 자체는 AI를 호출하지 않으며, "생성 시작", "현재 모델로 다시 스캔" 또는 "연결 테스트"를 클릭할 때만 요청이 전송됩니다. 언제든지 이 기능을 끄거나 동의를 철회할 수 있으며, 생성된 요약을 삭제하려면 설정에서 "설명 캐시 비우기"를 클릭하세요.

후원 링크

설정 오른쪽 상단의 커피 아이콘은 후원 링크일 뿐입니다. 중국어 간체에서는 확장 프로그램에 포함된 WeChat 후원 QR 이미지를 표시하고, 다른 언어에서는 Ko-fi(ko-fi.com)를 엽니다. 확장 프로그램에는 결제 SDK가 포함되어 있지 않으며 이 페이지들로 사용자의 데이터를 전송하지 않습니다.

하지 않는 일

  • 개인 식별 정보, 방문 기록 또는 사용 분석 데이터를 수집하지 않습니다.
  • 분석, 광고 또는 추적 코드를 사용하지 않습니다.
  • 사용자 데이터를 판매하거나 이전하지 않으며, 확장 프로그램의 단일 목적과 무관한 용도로 사용하지 않습니다.
  • 사용자 데이터를 신용도 판단이나 대출 목적으로 사용하지 않습니다.

Chrome 웹 스토어 사용자 데이터 정책

이 확장 프로그램의 사용자 데이터 사용은 제한된 사용(Limited Use) 요건을 포함하여 Chrome 웹 스토어 사용자 데이터 정책을 준수합니다.

아동 개인정보

이 확장 프로그램은 만 13세 미만 아동을 대상으로 하지 않으며, 아동의 정보를 고의로 수집하지 않습니다.
