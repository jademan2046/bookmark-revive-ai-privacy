Bookmark Revive AI · プライバシーポリシー

最終更新日：2026年11月27日

概要

Bookmark Revive AI（以下「本拡張機能」）は、忘れかけていたブックマークを再発見できるようにする Chrome の新しいタブ用拡張機能です。ローカルファースト設計で、開発者はサーバーを運用しておらず、お客様のデータを収集・受信・販売することは一切ありません。

本拡張機能が読み取り・変更するデータ

  • ブックマーク（bookmarks 権限）：新しいタブページでの表示、検索、ローテーション表示のために、ブックマークのタイトル、URL、フォルダを読み取ります。ブックマークを変更するのは、お客様が操作したときだけです。「Chrome のブックマークにも保存」を選んで「よく使う」に追加すると、お客様が選んだフォルダにブックマークが作成されます。同期を有効にして「よく使う」を編集すると、対応するブックマークの URL が更新されます。カードの「削除」をクリックし、2 回確認すると、そのブックマークが削除されます。
  • よくアクセスするサイト（topSites 権限）：初回インストール時に上位 8 件を初期の「よく使う」として使用します。また、「よくアクセスするサイトを優先」をオンにした場合に、重み付けの調整にも使用します。
  • サイトアイコン（favicon 権限）：Chrome 内蔵の API を通じて読み込みます。アイコン取得のためにお客様の URL を第三者へ送信することはありません。
  • アラーム（alarms 権限）：「すべてのブックマークの説明を生成」の実行中にのみ使用し、Chrome がバックグラウンドプロセスを停止した場合に未完了の処理を再開するために使います。

データの保存場所

「よく使う」と「候補」のリスト（タイトル、URL、並び順）は、Chrome 同期（chrome.storage.sync）によりお客様の Google アカウントに保存され、同じアカウントでログインしている他の端末で自動的に復元されます。Chrome にログインしていない場合や同期がオフの場合は、この端末にのみ保存されます。本拡張機能を削除すると、Chrome はこれらの同期データも削除します。その他のデータ（クリック回数、表示履歴、説明キャッシュ、設定、およびお客様が入力した API Key）は、ブラウザのローカル拡張機能ストレージ（chrome.storage.local）にのみ保存され、同期されることはありません。本拡張機能が開発者や開発者のサーバーにデータを送信することはありません（開発者はサーバーを運用していません）。設定ページからエクスポートした「AI 説明」のバックアップファイルは、お客様が選んだ場所にのみ保存され、API Key は含まれません。

オプション機能：AI による一言説明

  • この機能はデフォルトでオフです。設定ページのプライバシーに関する説明を読み、同意にチェックを入れ、ご自身の API Key を入力してスイッチをオンにした場合にのみ動作します。
  • オンにすると、本拡張機能は、説明の生成が必要なブックマークのタイトル、ドメイン、フォルダ名を、お客様のブラウザからお客様ご自身が選択した AI プロバイダーへ直接送信し、一言説明を生成します。リクエストにはお客様自身の API Key が使用され、料金はそのプロバイダーのお客様のアカウントに請求されます。
  • 組み込みのプロバイダー：DeepSeek（api.deepseek.com）、Google Gemini（generativelanguage.googleapis.com）。インストール時にこれらのドメインへのアクセス権は付与されません。AI をオンにして「保存」「接続テスト」または「取得」をクリックしたときにだけ、選択した 1 社のドメインへのアクセスを Chrome に申請します。拒否した場合、リクエストは一切送信されません。別のプロバイダーに切り替えると、以前のドメインへのアクセス権は取り消されます。
  • 「カスタムプロバイダー」を選択してエンドポイントを入力することもできます。その場合、本拡張機能は、お客様が「保存」「接続テスト」または「取得」をクリックしたときにのみ、入力された 1 つのドメインだけへのアクセスを Chrome に要求し、他のサイトへのアクセスを要求することはありません。別のエンドポイントに切り替えると、以前のドメインへのアクセス許可は取り消されます。
  • 送信しないもの：完全な閲覧履歴、ページの内容、Cookie、パスワード、その他の個人を特定できる情報。
  • 選択したプロバイダーによるこれらのデータの取り扱いは、そのプロバイダー自身のプライバシーポリシーに従います。ご利用前にご確認ください。
  • 生成された説明は URL ごとにローカルへキャッシュされ、再度送信されることはありません。新しいタブページ自体が AI を呼び出すことはなく、リクエストが送信されるのは「生成を開始」「現在のモデルで再スキャン」または「接続テスト」をクリックしたときだけです。この機能はいつでもオフにでき、同意を撤回することもできます。生成済みの説明を削除するには、設定ページで「説明キャッシュを消去」をクリックしてください。

サポート用リンク

設定ページの右上にあるコーヒーのアイコンは、サポート用リンクにすぎません。簡体字中国語の画面では、拡張機能に同梱された WeChat の投げ銭用 QR コード画像が表示され、その他の言語では Ko-fi（ko-fi.com）のページが開きます。本拡張機能には決済 SDK は含まれておらず、これらのページへお客様のデータを送信することもありません。

私たちが行わないこと

  • 個人を特定できる情報、閲覧履歴、利用状況の統計を収集しません。
  • 分析・広告・トラッキング用のコードを使用しません。
  • ユーザーデータを販売または譲渡せず、本拡張機能の単一の目的と無関係な目的にも使用しません。
  • ユーザーデータを、信用力の判断や貸付の目的に使用しません。

Chrome ウェブストア ユーザーデータポリシー

本拡張機能によるユーザーデータの使用は、「限定使用」の要件を含む Chrome ウェブストア ユーザーデータポリシーに準拠しています。

お子様のプライバシー

本拡張機能は 13 歳未満のお子様を対象としておらず、お子様の情報を意図的に収集することはありません。

本ポリシーの変更

本ポリシーに変更がある場合は、このページ上部の日付を更新します。データの使用方法に関わる重要な変更は、拡張機能のアップデート情報でお知らせします。
