Bookmark Revive AI · Kebijakan Privasi

Terakhir diperbarui: 27 November 2026

Ringkasan

Bookmark Revive AI ("ekstensi") adalah ekstensi tab baru Chrome yang membantu kamu menemukan kembali bookmark yang terlupakan. Ekstensi ini mengutamakan penyimpanan lokal: pengembang tidak menjalankan server apa pun dan tidak mengumpulkan, menerima, atau menjual data kamu.

Data yang dibaca dan diubah ekstensi

  • Bookmark (izin bookmarks): judul, URL, dan folder dibaca untuk ditampilkan, dicari, dan diputar di halaman tab baru. Bookmark hanya diubah saat kamu bertindak: menambahkan Favorit dengan "Also save to Chrome bookmarks" akan membuat bookmark di folder yang kamu pilih; mengedit Favorit saat sinkronisasi aktif akan memperbarui URL bookmark tersebut; mengklik "Delete" pada kartu dan mengonfirmasi dua kali akan menghapus bookmark tersebut.
  • Situs yang paling sering dikunjungi (izin topSites): 8 teratas dipakai sebagai Favorit awal saat pertama kali dipasang, dan untuk menyesuaikan pembobotan jika kamu mengaktifkan "boost frequently visited sites".
  • Ikon situs (izin favicon): dimuat melalui API bawaan Chrome; URL kamu tidak pernah dikirim ke pihak ketiga mana pun untuk mengambil ikon.
  • Alarm (izin alarms): hanya digunakan saat "Generate summaries for all bookmarks" sedang berjalan, untuk melanjutkan tugas jika Chrome menangguhkan proses latar belakang.

Tempat data disimpan

Daftar Favorit dan Kandidat kamu (judul, URL, dan urutan) disimpan di akun Google kamu melalui sinkronisasi Chrome (chrome.storage.sync), agar dapat dipulihkan otomatis di perangkat lain yang masuk dengan akun yang sama; jika kamu tidak masuk ke Chrome atau sinkronisasi nonaktif, data ini hanya tersimpan di perangkat ini. Menghapus ekstensi akan membuat Chrome ikut menghapus data sinkronisasi ini. Semua data lainnya (jumlah klik, riwayat tampilan, cache ringkasan, pengaturan, dan API Key yang kamu masukkan) hanya disimpan di penyimpanan ekstensi lokal browser kamu (chrome.storage.local) dan tidak pernah disinkronkan. Ekstensi ini tidak pernah mengirim data apa pun ke pengembang atau server pengembang (pengembang tidak menjalankan server). File cadangan ringkasan AI yang kamu ekspor dari Pengaturan hanya disimpan di lokasi pilihanmu dan tidak berisi API Key.

Fitur opsional: ringkasan satu baris dari AI

  • Fitur ini nonaktif secara default. Fitur hanya berjalan setelah kamu membaca pemberitahuan privasi di Pengaturan, mencentang kotak persetujuan, memasukkan API Key milikmu sendiri, lalu mengaktifkannya.
  • Saat aktif, ekstensi mengirimkan judul, domain, dan nama folder dari bookmark yang memerlukan ringkasan langsung dari browser kamu ke penyedia AI pilihan kamu untuk membuat ringkasan satu baris. Permintaan menggunakan API Key milikmu sendiri dan ditagihkan ke akun kamu di penyedia tersebut.
  • Penyedia bawaan: DeepSeek (api.deepseek.com) dan Google Gemini (generativelanguage.googleapis.com). Tidak ada akses ke domain ini yang diberikan saat pemasangan: hanya ketika kamu mengaktifkan AI dan mengklik "Simpan", "Uji koneksi", atau "Ambil", ekstensi meminta Chrome akses ke satu penyedia yang kamu pilih. Jika kamu menolak, tidak ada permintaan yang dikirim. Jika kamu beralih ke penyedia lain, akses ke domain lama dicabut.
  • Kamu juga bisa memilih "Custom provider" dan memasukkan endpoint. Dalam hal ini, ekstensi meminta akses ke Chrome untuk domain itu saja, dan hanya saat kamu mengklik "Save", "Test connection", atau "Fetch"; ekstensi tidak pernah meminta akses ke situs lain mana pun. Jika kamu beralih ke endpoint lain, akses ke domain lama akan dicabut.
  • Tidak pernah dikirim: riwayat penjelajahan lengkap, isi halaman, cookie, kata sandi, atau informasi pribadi apa pun yang dapat mengidentifikasi kamu.
  • Cara penyedia pilihan kamu menangani data ini diatur oleh kebijakan privasi penyedia tersebut; harap tinjau sebelum menggunakannya.
  • Ringkasan disimpan dalam cache secara lokal berdasarkan URL dan tidak dikirim lagi. Halaman tab baru itu sendiri tidak pernah memanggil AI; permintaan hanya dikirim saat kamu mengklik "Mulai buat ringkasan", "Pindai ulang dengan model saat ini", atau "Uji koneksi". Kamu dapat menonaktifkan fitur ini atau menarik persetujuan kapan saja; untuk menghapus ringkasan yang telah dibuat, klik "Kosongkan cache ringkasan" di Pengaturan.

Tautan dukungan

Ikon kopi di kanan atas Pengaturan hanyalah tautan dukungan: dalam bahasa Mandarin Sederhana, ikon ini menampilkan gambar QR donasi WeChat yang disertakan dalam ekstensi; dalam bahasa lain, ikon ini membuka Ko-fi (ko-fi.com). Ekstensi tidak menyertakan SDK pembayaran dan tidak mengirimkan data kamu ke halaman-halaman ini.

Yang tidak kami lakukan

  • Kami tidak mengumpulkan informasi pribadi yang dapat mengidentifikasi kamu, riwayat penjelajahan, atau analitik penggunaan.
  • Kami tidak menggunakan kode analitik, iklan, atau pelacakan.
  • Kami tidak menjual atau mentransfer data pengguna, atau menggunakannya untuk tujuan yang tidak terkait dengan tujuan tunggal ekstensi.
  • Kami tidak menggunakan data pengguna untuk menentukan kelayakan kredit atau untuk keperluan pinjaman.

Kebijakan Data Pengguna Chrome Web Store

Penggunaan data pengguna oleh ekstensi ini mematuhi Kebijakan Data Pengguna Chrome Web Store, termasuk persyaratan Penggunaan Terbatas.

Privasi anak

Ekstensi ini tidak ditujukan untuk anak di bawah 13 tahun dan tidak dengan sengaja mengumpulkan informasi dari anak-anak.

Perubahan pada kebijakan ini

Jika kebijakan ini berubah, kami akan memperbarui tanggal di bagian atas halaman ini. Perubahan material pada cara data digunakan akan diumumkan dalam catatan pembaruan ekstensi.
