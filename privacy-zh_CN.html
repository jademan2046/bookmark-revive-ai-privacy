拾贝书签 · 隐私政策

最后更新：2026 年 11 月 27 日

概述

拾贝书签（以下简称「本扩展」）是一个 Chrome 新标签页扩展，帮你重新发现收藏夹里沉睡的书签。本扩展坚持本地优先：开发者不运营任何服务器，不收集、不接收、不出售你的任何数据。

本扩展读取和修改哪些数据

  • 书签（bookmarks 权限）：读取书签的标题、网址和所在文件夹，用于在新标签页展示、搜索和轮换推荐。只在你主动操作时修改书签：添加常用项并选择「同时写入 Chrome 系统书签」时，在你选定的文件夹里新建一条书签；编辑常用项并勾选同步时，更新对应书签的网址；在拾遗卡上点「删除」并两次确认后，删除该书签。
  • 最常访问的网站（topSites 权限）：首次安装时取前 8 个作为初始常用项；你开启「高频站点加权」后用于调整推荐权重。
  • 网站图标（favicon 权限）：通过 Chrome 内置接口读取，不会把你的网址发给任何第三方。
  • 定时器（alarms 权限）：只在「初始化全书签说明」运行期间使用，用于在浏览器回收后台进程后继续未完成的任务。

数据存在哪里

常用列表与候选列表（标题、网址和顺序）会通过 Chrome 同步（chrome.storage.sync）保存在你的 Google 账号中，用于在你登录同一账号的其他设备上自动恢复；未登录 Chrome 或关闭同步时只保存在本机。删除本扩展后，Chrome 会一并清除这些同步数据。其余数据（点击次数、曝光记录、说明缓存、设置，以及你填写的 API Key）都只保存在你本机 Chrome 的扩展存储中（chrome.storage.local），从不同步。本扩展不会把任何数据发给开发者或开发者的服务器（开发者不运营服务器）。你在设置页导出的「AI 说明」备份文件只保存在你自己选择的位置，不含 API Key。

可选功能：AI 一句话说明

  • 此功能默认关闭。只有在你阅读设置页的隐私说明、勾选同意、填入你自己的 API Key 并开启开关后才会运行。
  • 开启后，本扩展会把需要生成说明的书签的标题、域名和所在文件夹名称，从你的浏览器直接发送给你自己选择的 AI 服务商，用于生成一句话说明。请求使用你自己的 API Key，费用由你在该服务商的账户承担。
  • 内置可选的服务商：DeepSeek（api.deepseek.com）、Google Gemini（generativelanguage.googleapis.com）。安装时不会获得这些域名的访问权限：只有在你开启 AI 并点「保存」「测试连接」或「拉取」时，本扩展才会向 Chrome 申请访问你所选那一家的域名；你拒绝则不会发出任何请求。换用其他服务商后，旧域名的授权会被收回。
  • 你也可以选择「自定义服务商」并填写接口地址。此时，本扩展只会在你点击「保存」「测试连接」或「拉取」时，向 Chrome 申请访问你填写的那一个域名，不会申请其他任何网站的权限；换用其他地址后，旧域名的授权会被收回。
  • 不会发送：完整浏览记录、网页内容、Cookie、密码或任何个人身份信息。
  • 你所选服务商对这些数据的处理，受该服务商自己的隐私政策约束，请在使用前自行查阅。
  • 生成的说明按网址缓存在本机，再次出现时不会重复发送。新标签页本身从不调用 AI，请求只会在你点「开始初始化」「用当前模型重扫」或「测试连接」时发出。你可以随时关闭开关或撤回同意；如需删除已生成的说明，请在设置页点「清空说明缓存」。

打赏入口

设置页右上角的咖啡图标仅是一个打赏入口：简体中文界面显示随扩展打包的微信赞赏码图片；其他语言打开 Ko-fi 网页（ko-fi.com）。本扩展不集成任何支付 SDK，也不会向这些页面发送你的任何数据。

我们不做的事

  • 不收集个人身份信息、浏览记录或使用统计。
  • 不使用分析、广告或追踪代码。
  • 不出售或转让用户数据，也不将其用于与本扩展单一用途无关的目的。
  • 不使用用户数据判断信用资质或用于借贷目的。

Chrome 应用商店用户数据政策

本扩展对用户数据的使用遵守 Chrome 应用商店用户数据政策，包括其中的「有限使用」要求。

儿童隐私

本扩展不面向 13 岁以下儿童，也不会有意收集儿童的信息。

政策变更

本政策如有变化，会更新本页顶部的日期；涉及数据使用方式的重大变化会在扩展更新说明中告知。
