Bookmark Revive AI · Политика конфиденциальности

Последнее обновление: 24 ноября 2026 г.

Обзор

Bookmark Revive AI («расширение») — это расширение для новой вкладки Chrome, которое помогает заново находить забытые закладки. Оно работает по принципу «сначала локально»: разработчик не использует серверов и не собирает, не получает и не продаёт ваши данные.

Какие данные расширение читает и изменяет

  • Закладки (разрешение bookmarks): названия, URL-адреса и папки читаются для отображения, поиска и ротации на странице новой вкладки. Закладки изменяются только по вашему действию: добавление элемента в Избранное с пунктом «Также сохранить в закладки Chrome» создаёт закладку в выбранной вами папке; редактирование элемента Избранного при включённой синхронизации обновляет URL этой закладки; нажатие «Удалить» на карточке и двойное подтверждение удаляет эту закладку.
  • Часто посещаемые сайты (разрешение topSites): первые 8 используются как начальное Избранное при первой установке, а также для корректировки весов, если вы включите «учитывать часто посещаемые сайты».
  • Значки сайтов (разрешение favicon): загружаются через встроенный API Chrome; ваши URL-адреса никогда не передаются третьим лицам для получения значков.
  • Будильники (разрешение alarms): используются только во время работы функции «Создать описания для всех закладок», чтобы возобновить задачу, если Chrome приостановит фоновый процесс.

Где хранятся данные

Все данные (Избранное, Кандидаты, число кликов, история показов, кэш описаний, настройки и введённые вами API Key) хранятся только в локальном хранилище расширений вашего браузера (chrome.storage.local). Они никогда не синхронизируются с разработчиком или каким-либо сервером. При удалении расширения эти данные удаляются.

Дополнительная функция: однострочные описания от ИИ

  • Эта функция по умолчанию выключена. Она работает только после того, как вы прочитаете уведомление о конфиденциальности в настройках, отметите флажок согласия, введёте собственный API Key и включите её.
  • Когда функция включена, расширение отправляет название, домен и название папки закладок, которым нужно описание, прямо из вашего браузера выбранному вами провайдеру ИИ для создания однострочного описания. Запросы используют ваш собственный API Key и оплачиваются с вашей учётной записи у этого провайдера.
  • Встроенные провайдеры: DeepSeek (api.deepseek.com) и Google Gemini (generativelanguage.googleapis.com). Доступ к этим двум доменам предоставляется при установке.
  • Вы также можете выбрать «Свой провайдер» и указать адрес конечной точки. В этом случае расширение запрашивает у Chrome доступ только к этому одному домену и только когда вы нажимаете «Сохранить», «Проверить подключение» или «Загрузить»; доступ к любым другим сайтам оно не запрашивает. Если вы переключитесь на другую конечную точку, доступ к прежнему домену отзывается.
  • Никогда не отправляются: полная история просмотров, содержимое страниц, файлы cookie, пароли и любые персональные данные.
  • Обработка этих данных выбранным вами провайдером регулируется собственной политикой конфиденциальности провайдера; ознакомьтесь с ней перед использованием.
  • Описания кэшируются локально по URL и повторно не отправляются. Сама страница новой вкладки никогда не обращается к ИИ; запросы отправляются только когда вы нажимаете «Начать создание» или «Проверить подключение». Вы можете в любое время выключить функцию или отозвать согласие; чтобы удалить созданные описания, нажмите «Очистить кэш описаний» в настройках.

Ссылка для поддержки

Значок кофе в правом верхнем углу настроек — это лишь ссылка для поддержки: в интерфейсе на упрощённом китайском он показывает изображение QR-кода для пожертвований через WeChat, входящее в состав расширения; в остальных языках открывается Ko-fi (ko-fi.com). Расширение не содержит платёжных SDK и не отправляет на эти страницы никаких ваших данных.

Чего мы не делаем

  • Мы не собираем персональные данные, историю просмотров или статистику использования.
  • Мы не используем код аналитики, рекламы или отслеживания.
  • Мы не продаём и не передаём данные пользователей и не используем их в целях, не связанных с единственным назначением расширения.
  • Мы не используем данные пользователей для оценки кредитоспособности или в целях кредитования.

Политика Chrome Web Store в отношении пользовательских данных

Использование пользовательских данных этим расширением соответствует Политике Chrome Web Store в отношении пользовательских данных, включая требования об ограниченном использовании.

Конфиденциальность детей

Расширение не предназначено для детей младше 13 лет и сознательно не собирает информацию о детях.

Изменения политики

Если эта политика изменится, мы обновим дату в верхней части страницы. О существенных изменениях в использовании данных будет сообщено в примечаниях к обновлению расширения.
