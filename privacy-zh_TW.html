拾貝書籤 · 隱私權政策

最後更新：2026 年 11 月 24 日

概述

拾貝書籤（以下簡稱「本擴充功能」）是一個 Chrome 新分頁擴充功能，幫助你重新發現收藏夾裡沉睡的書籤。本擴充功能堅持本機優先：開發者不營運任何伺服器，不蒐集、不接收、不販售你的任何資料。

本擴充功能讀取和修改哪些資料

  • 書籤（bookmarks 權限）：讀取書籤的標題、網址和所在資料夾，用於在新分頁顯示、搜尋和輪替推薦。只在你主動操作時修改書籤：新增常用項並選擇「同時寫入 Chrome 系統書籤」時，在你選定的資料夾裡新增一筆書籤；編輯常用項並勾選同步時，更新對應書籤的網址；在拾遺卡上點選「刪除」並兩次確認後，刪除該書籤。
  • 最常造訪的網站（topSites 權限）：首次安裝時取前 8 個作為初始常用項；你開啟「高頻網站加權」後用於調整推薦權重。
  • 網站圖示（favicon 權限）：透過 Chrome 內建介面讀取，不會把你的網址傳送給任何第三方。
  • 計時器（alarms 權限）：只在「初始化全書籤說明」執行期間使用，用於在瀏覽器回收背景處理程序後繼續未完成的工作。

資料存放在哪裡

所有資料（常用項、候選、點擊次數、曝光記錄、說明快取、設定，以及你填寫的 API Key）都只儲存在你本機 Chrome 的擴充功能儲存空間中（chrome.storage.local），不會同步給開發者或任何伺服器。解除安裝本擴充功能後，Chrome 會一併刪除這些資料。

選用功能：AI 一句話說明

  • 此功能預設關閉。只有在你閱讀設定頁的隱私說明、勾選同意、填入你自己的 API Key 並開啟開關後才會執行。
  • 開啟後，本擴充功能會把需要產生說明的書籤的標題、網域和所在資料夾名稱，從你的瀏覽器直接傳送給你自己選擇的 AI 服務供應商，用於產生一句話說明。請求使用你自己的 API Key，費用由你在該服務供應商的帳戶承擔。
  • 內建可選的服務供應商：DeepSeek（api.deepseek.com）、Google Gemini（generativelanguage.googleapis.com）。這兩個網域在安裝時即獲授權。
  • 你也可以選擇「自訂服務供應商」並填寫介面位址。此時，本擴充功能只會在你點選「儲存」「測試連線」或「拉取」時，向 Chrome 申請存取你填寫的那一個網域，不會申請其他任何網站的權限；改用其他位址後，舊網域的授權會被收回。
  • 不會傳送：完整瀏覽記錄、網頁內容、Cookie、密碼或任何個人身分資訊。
  • 你所選服務供應商對這些資料的處理，受該服務供應商自己的隱私權政策約束，請在使用前自行查閱。
  • 產生的說明依網址快取在本機，再次出現時不會重複傳送。新分頁本身從不呼叫 AI，請求只會在你點選「開始初始化」或「測試連線」時發出。你可以隨時關閉開關或撤回同意；如需刪除已產生的說明，請在設定頁點選「清空說明快取」。

贊助入口

設定頁右上角的咖啡圖示僅是一個贊助入口：簡體中文介面顯示隨擴充功能封裝的微信讚賞碼圖片；其他語言開啟 Ko-fi 網頁（ko-fi.com）。本擴充功能不整合任何支付 SDK，也不會向這些頁面傳送你的任何資料。

我們不做的事

  • 不蒐集個人身分資訊、瀏覽記錄或使用統計。
  • 不使用分析、廣告或追蹤程式碼。
  • 不販售或轉讓使用者資料，也不將其用於與本擴充功能單一用途無關的目的。
  • 不使用使用者資料判斷信用資格或用於借貸目的。

Chrome 線上應用程式商店使用者資料政策

本擴充功能對使用者資料的使用遵守 Chrome 線上應用程式商店使用者資料政策，包括其中的「有限使用」要求。

兒童隱私

本擴充功能不以 13 歲以下兒童為對象，也不會有意蒐集兒童的資訊。

政策變更

本政策如有變更，會更新本頁頂部的日期；涉及資料使用方式的重大變更會在擴充功能更新說明中告知。
